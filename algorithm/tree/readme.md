# 树和二叉树

- 一棵树只有一个树根
- 向上伸展出无线的树枝（非线性） child
- 树枝上会有树叶 leaf

数据结构中的树（tree）是对自然界树的一个抽象
- 树根 -> 根节点 root node
- 树枝 -> 边 child 
- 树枝的两个端点抽象为节点 -> node
- 树叶 -> 叶子节点 leaf node

## 树的核心概念
- 树的层次 
    根节点为第一层，依次+1
- 高度
    从叶子节点开始计算
- 度
    一个节点开叉多少个子树（子树的数量）
- 叶子节点 
    度为0的节点（没有后续节点）

## 什么是二叉树
**递归的概念定义树**、树是重复的
- 它可以没有根节点，作为一棵空树存在
- 如果不是空树，那么必须由根节点、左子树、右子树组成。
    且左右子树都是二叉树（但是可以存在一边为空，另一边为二叉树）
   - 退出节点：自身为空，且左右子树为空
   - 左右之分 
注：
   二叉树不可以被简单的定义为度为2的树，每个节点的度都为2也不完全是二叉树
   左右子树的顺序是严格的，不能任意交换。

## 二叉树节点定义

- 左节点的引用 left
- 右节点的引用 right
